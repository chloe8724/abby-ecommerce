# AI Usage Notes

This student prototype was created with AI assistance for the HTML structure, responsive styling, JavaScript interactions, and documentation. The implementation uses plain HTML5, CSS3, and vanilla JavaScript; no framework, backend, database, payment, or API integration is included.

## Data and limitations

- Product names, quantities, prices, and original SVG illustrations are demo content. Prices are illustrative and are not represented as verified Abby prices.
- Store details were transcribed from the user-provided assignment brief and included only for prototype display. They are not verified against current store operations or inventory.
- The confirmation message is local to the browser and does not create or submit an order.
- Google Fonts is an optional remote font source; system fonts are used if it is unavailable.

Please review the store data and functionality against the assignment brief before presenting or submitting the project.
